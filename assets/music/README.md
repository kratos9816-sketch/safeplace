# Background Music Guide

To use your own custom romantic song or instrumental track:
1. Place your audio file in this directory: `assets/music/`
2. Name it: `universe-theme.mp3` (or `.m4a`, `.wav`, `.ogg`)
3. The website will automatically detect and play your custom audio!
4. If no custom file is present, the website features a built-in soothing Web Audio API celestial romantic piano synthesizer that plays seamlessly out of the box.

Recommended styles:
- Soft romantic piano
- Cinematic acoustic strings
- Ambient celestial guitar / lofi love instrumental
